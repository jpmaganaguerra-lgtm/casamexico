Conexión con GitHub

El backoffice publica directamente en tu repositorio: cada vez que guardas, se hace un commit real a la rama que elijas.

Genera uno en GitHub → Settings → Developer settings → Fine-grained tokens, con permiso Contents: Read and write limitado a este repositorio. No se envía a ningún lado más que a api.github.com.
